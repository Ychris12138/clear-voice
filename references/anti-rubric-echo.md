# 限定表达与防御性免责分流规范（Q1-Q4 Local-Span Specification v1.1.3）

专业文稿审改既要剥离自动化流水线的机械免责复读，又必须守住统计不确定性、因果边界、偏倚说明与法律条款。`v1.1.3` 采用**拆壳感知的局部语义片段级（Math-Unwrapped Local-Span）**识别，支持中英文双语安全分句与有界非贪婪提取，匹配部分常见限定，具体判断仍需依靠研究语境。

## 一、Q1 至 Q4 分流矩阵

| 分类代码 | 识别标准 | 性质定性 | 标准动作 |
| :--- | :--- | :--- | :--- |
| **Q1：后台流程自白与空转纪律背诵** | 汇报检索动作（“按已完成知识库整理 / 未新增调查”），或在源材料未混淆时背诵提示词禁令（“不得将模拟与通用计算混为一谈”）。 | 冗余审计回声 | **按信息功能压缩**。影响覆盖范围、判断或可复现性的部分应留在相应位置。 |
| **Q2：全篇通用材料口径声明** | 整篇报告共用的材料前提（如“BP 财务预测未经独立审计”）。 | 全局证据边界 | **集中交代共用口径**。摘要、图注或其他会被单独阅读的内容保留理解结论所需的边界。 |
| **Q3-A：具体事实缺口** | 某项关键指标、验收水单、币种或实验对照确实未披露。 | 局部关键缺失 | **正面直陈缺口**，保持“未确定”状态，严禁推断补全。 |
| **Q3-B：主体归属风险** | 源材料将创始人高校旧作、前雇主成果或外部接口混写为初创公司自有实测。 | 主体错位风险 | **真实主语前置**（记入 `Semantic Change Trace` 供人工复核）。 |
| **Q3-C：结论适用范围限制** | 指标仅在特定温压、单芯片小规模或特定商业前提下成立。 | 外推适用边界 | **条件入主句**，直接写明成立前提与待扩展瓶颈。 |
| **Q4：必要专业限定** | 统计区间/显著性、因果未确立声明、偏倚/混杂边界、特定实验条件限制及法定合同义务。 | **专业底线** | **保留证据含义与范围**。措辞可调整，语义拿不准时沿用原句。 |

## 二、局部语义片段级 Q4 三态机制（Local-Span Tri-State Q4）

1. **行内公式拆壳、局部干扰词屏蔽与防吞噬边界**：
   - `prose_lint.py` 在提取 `Q4` 前保留行内公式内部的统计文本（将 `$p < 0.001$`、`$n = 64$`、`$\pm 0.04$` 拆壳供 `Q4` 扫描），在局部字符偏移上屏蔽“提示词、系统提示、弹窗提示、扩大访谈样本量、不得将 X 混为一谈”等非限定短语，并在连词免责边界处截断候选片段，使句内剩余机械免责回声仍被独立检出。
2. **三态定义与权限边界**：
   - **`Q4_PROTECTED`（高置信结构化限定片段）**：带定量统计区间与检验值（`95% CI`、`p < 0.001`、`n = 64`、`HR = 0.72`、`± SD`）或带明确条款号的跨分句法定权责片段（`根据采购协议第 5.2 条，买方不得……，供应商应当……`）。
   - **`Q4_CANDIDATE`（局部语境限定候选片段）**：涵盖中英文**因果未确立**（`尚未/未能证实因果关系`、`does not establish a causal relationship`）、**偏倚与误差边界**（`无法/不排除存在选择/幸存者偏倚`、`可能受混杂因素影响`、`could not rule out selection biases`）、**实验与适用条件限制**（`仅适用于当前实验条件`、`仅在 230 K 至 250 K 下成立`、`holds only under ambient pressure`）、**样本量与相关性审慎词**（`在当前样本量下未观察到……`、`analysis suggests...`）及未带条款号的权责情态词。Python 将每个候选片段写入 `q4_items`（`auto_delete_authorized: false`）供 LLM 或人工复核。
   - **`Q4_NOT_QUALIFICATION`（未检出显式限定片段）**：**仅代表启发式规则未在该句中匹配到显式 Q4 模式，绝不代表已获得语义删除授权**。Python 严禁直接删除任何正文句子；凡不确定某句是否承担边界限定功能，默认保留原文。

## 三、跨平台本机路径分级警告规范（只警告，不擅自盲删）

- **`SEM-04`（隐私敏感路径警告）**：匹配个人主目录（含无尾斜杠 `/Users/name` 与含空格用户名 `C:\Users\Lin Wei\...`）、隐藏凭据配置目录（`~/.ssh`、`~/.aws`、`~/.config`）、临时目录（`(?:/private)?/var/folders/...`）、网络共享（`\\host\share`）或私有挂载卷（`/Volumes/My Passport/...`、`/(run/)media/...`）。个人电脑附件死链应改为纯文本页码说明。
- **`SEM-05`（一般本机/系统路径警告）**：匹配 `/opt/...`、`/mnt/...`、`/etc/...`、`D:\Data\...` 等不重叠系统路径，保留原始路径名提示人工判断是否具工程或科研复现价值。
