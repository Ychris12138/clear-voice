# 垂直领域保护包：投研评审与商业尽调（Due Diligence Pack）

适用于风险投资项目初筛（BP 分诊）、技术尽职调查、行业竞品调研与并购评估备忘录。核心准则是**“只抓材料吹过的牛，不背自己守过的规矩”**。

## 一、刚性保护白名单（严禁在润色中弱化或改写）

1. **财务与订单口径边界**：严格保留意向书（LOI）、框架协议、采购订单（PO）、已验收交付、确认收入（Recognized Revenue）与实际回款之间的区分。
2. **币种与量纲原貌**：原文币种不明（如仅写 `$` 未区分美元、新元或加元）时，保留原符号并在括号内简注 `（原文记为 $，确切币种待核）`。
3. **主体与资产归属切割**：准确区分美国/新加坡/境内不同法律主体全称，明确区分“创始人高校实验室过往论文成果”与“公司成立后自有设备实测数据”。
4. **同名主体防撞提示**：赛道内存在易混淆同名公司时，在主体介绍处用一句大白话点明无关联。

## 二、尽调文稿四大重灾区与正向改法

| 重灾区类型 | 机器味原句特征 | 专业投资人自然写法 |
| :--- | :--- | :--- |
| **句末免责复读** | 每写完一项产品或专利都补一句“本轮未取得第三方验证，不代表公司已实现商业化”。 | 文首副标题统一标注核验口径；正文直接写“该指标目前仅见于 BP 路线图，尚缺本机实测报告”。 |
| **只堆术语不讲账本** | 照抄 BP 里的物理/算法黑话（如“采用参数调制门与多芯片耦合架构”），不解释商业含义。 | 点破工程权衡：说明该方案省了哪块成本、卡在哪道良率或保真度门槛上。 |
| **章节同义反复** | 速览表写一遍缺测试数据，技术节写一遍，风险节又抄一遍，问题清单再问一遍。 | 速览表列现状底牌，技术节分析卡点原因，末节浓缩为 3 至 5 个上会追问的具体问题。 |
| **空泛跟进建议** | 结尾写“建议持续关注公司后续研发进展与市场开拓情况”。 | 给出明确分诊动作：“建议约一次技术交流，优先索取单机实测保真度分布图与首笔订单验收条件”。 |

## 三、上会追问清单（Checklist）写法示范

尽调报告结尾的核查问题应直接写成**可当面发问的具体索证动作**，省去空洞套话：

- **查当期真机底牌**：目前实验室里同时可用比特数最多的一台样机，单比特门、双比特门与读取保真度中位数分别是多少？能否提供近期连续运行标定曲线？
- **查核心扩容易用性**：多芯片互连目前跑通了双芯片跨桥纠缠实验，还是仍停留在单芯片验证阶段？跨芯片传输损耗比片内高多少？
- **查订单含金量**：账面披露的采购订单对应哪几家具体客户、交付标的物是整机还是测控模块、合同约定的验收节点与首付款到账比例是多少？
