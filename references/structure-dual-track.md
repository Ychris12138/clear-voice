# 文档级与章节级两层结构路由及长文执行协议（v1.1.3）

专业文稿常兼具多种表达任务：技术尽调报告里会有创业沿革叙述，深度科普长文里也会有严谨的实验步骤清单。结构优化采用**“文档级主基调 + 章节级局部适配”**两层路由，并支持跨学科文稿叠加加载多个领域保护包。

## 一、两层结构路由规则（Document + Section Routing）

1. **文档级主基调（Document Baseline）**：先判断全文主要服务于“快速核清事实与决策（Analytical）”还是“连贯叙事与观点传递（Narrative）”。
2. **章节级局部切换（Section-Level Override）**：
   - **分析文档不强制使用摘要表**：多维横向比选或初筛报告适合在文首（前 45 行且第一个 `##` 节内）放置单元格自洽的速览表（`SEM-01` 仅检查文首速览表，不误判后文或文末附录数据表）；短篇评审、同行审稿意见或单点备忘录可直接进入正文，无需硬凑表格。
   - **分析文档允许自然叙述节**：背景沿革、物理图像解释或事故经过章节可保持连贯段落，不必强拆成碎列表。
   - **叙事文档允许保留功能性列表**：遇到真实操作步骤、核查清单或并列条件时保留清晰列表，仅拆解把连贯论点切碎的“口号式伪列表”。
3. **多领域保护包并集加载（Multi-Pack Union）**：跨学科文稿可同时加载多个 `domain-packs/*.md`，取各保护白名单的并集执行豁免。

## 二、长文模式（Agent 执行协议，非 Python 自动分段引擎）

> **实现边界说明**：长文模式目前是供 **Agent 遵循的结构化执行协议**，并非 Python 脚本内置的自动切块重写引擎。`scripts/prose_lint.py` 仅负责确定性统计正文（剔除标题行、受保护代码块/公式/Frontmatter 并剥离 Markdown 链接 URL 后）的字词与标题数量，输出 `long_doc_agent_protocol_recommended` 提示布尔值，不会对文稿做自动切分。

### 1. 可参考的篇幅提示

- **中文字符阈值**：正文中文字符数 **`>= 3,000` 字**；
- **英文单词阈值**：正文英文单词数 **`>= 1,800` 词（words）**；
- **章节规模阈值**：包含 **`>= 4` 个二级标题章节（`##`）**。

这些阈值提示全篇可能需要一致性检查。是否分节复核取决于论证复杂度、跨节共用数据和本轮改动范围。

### 2. 分节改写与跨节核对

1. **改前锁定全局一致性字典**：由 Agent 先提取并冻结全篇统一的主体简称表、核心数值与量纲表、证据等级口径以及 `Q2` 全局声明的唯一安放位置。
2. **携带字典按节改写**：Agent 每次处理 1 至 2 个相邻章节，按该节局部功能选用段落或列表；前文已详述的背景事实在后文仅作简短指代，消除跨节同义抄写。
3. **改后跨章节一致性核对**：通读核对摘要与各分节的数字、单位、肯定/否定极性、主体称谓及 `Q4` 限定词完全一致，需要检查 Markdown 时可对整稿做只读扫描。
