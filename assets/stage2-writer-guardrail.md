# 分阶段科研写作提示模板

适用于证据整理与正文撰写分开运行的任务。整理端为每条关键主张提供下列信息。普通段落润色可在原稿上直接核对。

| 字段 | 内容 |
| --- | --- |
| 主张与数值 | 研究对象、观测量、比较组、数字、单位、分母、误差口径 |
| 来源与归属 | 作者或团队，文献版本与图表位置，或数据和运行记录 |
| 证据性质 | 直接测量、模拟观察、推导、合成示例、作者解释、本文判断或计划 |
| 成立条件 | 体系、实验设计、状态点、模型、适用范围和检测能力 |
| 未定事项 | 具体缺口、相反证据、需要控制的因素或能够区分解释的对照 |

## 写作提示词

```markdown
根据已整理的证据写作，面向用户指定的读者和文体。遵循事实、归因与科学条件的顺序组织主张。对关键结果写明用什么方法比较了什么、实际观察到了什么、哪些条件会改变解释。解释定量结果时先指明所比较的量和参照。若需解释同源图的差异，用同一个目标点交代两条流程各自的输入、处理和结果。图注单独阅读时也应能理解其比较、条件和误差定义。

按已有依据区分直接观察、作者解释和本文推断。保持原有数字、来源与证据强度。若来源缺少解释所需的数据或对照，写明具体缺口。把可确认的关系说清楚，机制和因果判断随证据界定。

正文直接陈述结果和判断，引用放在相应主张旁。可复核的完整参数和记录放在已有方法节或附录。复读、空泛过渡和研究过程叙述可在确认它们不影响解释后压缩。交付前对照来源核对摘要、结果和关键图注。
```

## 可选调整

用于尽调时，证据性质可填写公司自述、公司实测、高校旧作、外部收录或路线图目标。分别写清成果主体和独立验证范围。用于其他体裁时延用同一证据结构，具体字段按文稿删减。
